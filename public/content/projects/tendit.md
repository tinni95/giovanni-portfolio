# Tendit - Task Management Platform

A modern, intuitive task management platform designed for teams and individuals to streamline their workflow and boost productivity.

## Project Overview

Tendit is a comprehensive project management solution that combines the simplicity of task lists with the power of advanced project tracking, team collaboration, and analytics.

## Key Features

- **Kanban Boards**: Visual project management
- **Team Collaboration**: Real-time updates and comments
- **Time Tracking**: Built-in productivity analytics
- **Integration Hub**: Connect with popular tools
- **Custom Workflows**: Tailored to your team's needs

## Technologies Used

- **Frontend**: React, Redux, Material-UI
- **Backend**: Node.js, Express, MongoDB
- **Real-time**: Socket.io
- **Authentication**: JWT, OAuth 2.0
- **Testing**: Jest, Cypress
